PF-05 · Mensajes para el cliente de prueba MQTT de AWS IoT (RF11)

Tópico de publicación: smartpark/smartpark-grupo9-01/history/v1
Formato: contrato del histórico (docs/historial-aws-practica-4.md). El objeto publica
eventId, occurredAt, eventType, origin y data; la regla SmartParkHistoryIngest agrega
thingName, schemaVersion y receivedAt. Validación: validate_event() en
lambda/history_lambda_function.py.

Cada cuerpo inválido es una lectura "sample" válida con un único campo cambiado.
occurredAt (1795000000000) es una hora pasada, para que la validación llegue al campo
que se prueba. Ninguno se almacena.
